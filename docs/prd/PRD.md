# Breathwork PRD

繁體中文、台灣使用者。這不是通用冥想 App。MVP 是一支手機優先的體驗播放器：呼吸、音樂、視覺、中文肯定句，把當下狀態帶往想去的狀態。

## 誰在用

想用很短的一段時間，從拖延、自我懷疑、焦慮或睡前雜念，走到一個比較能行動、能信任自己、能放下的狀態。

## 核心流程

首頁 → 選一個意向 → 調整這一輪 → 播放 → 完成。

五個預設：

| id | 標題 | 一句話 |
| --- | --- | --- |
| start | 開始行動 | 把拖延留在這一小段呼吸裡，先動一步。 |
| trust | 相信自己 | 把懷疑放輕，回到自己的選擇。 |
| ease | 放下焦慮 | 讓這一口氣比念頭更近。 |
| sleep | 睡前放下 | 把白天還沒想完的，先放在門外。 |
| four78 | 4-7-8 | 鼻子吸四拍，閉氣七拍，嘴巴慢慢吐八拍。 |

前四個預設每一輪 3 分鐘，呼吸固定為吸氣 4 秒、吐氣 6 秒，閉氣為 0。4-7-8 是 10 分鐘：開頭 15 秒、30 圈（吸 4、閉 7、吐 8）、結尾 15 秒。使用者不能改呼吸。

## 這一輪可以改什麼

- 音樂：Ambient、Organic、Deep。本地佔位循環，不是正式配樂。
- 視覺：光球、波、粒子。
- 肯定句：每個預設 6 句。可關、可改、可加，最多 8 句。至少留下一句才可以開始。

## 播放

全螢幕。視覺在吸氣時變大、吐氣時變小。畫面上有吸氣／吐氣、該相位剩餘秒數、目前肯定句、進度、暫停／繼續、離開。肯定句慢慢淡入淡出。音樂在開始時淡入，自然結束時淡出。離開立刻停音。

## 優先級

P0 是上面這條流程，而且只做在 Mobile。

本次不做：登入、付費、社群、AI 生成、Firebase、自訂呼吸、過度換氣、Web 上的播放器、Tone.js、對外 REST。閉氣只出現在 4-7-8。

## 成功看起來像什麼

使用者用手機寬度的瀏覽器，不接後端，可以選意向、改音樂／視覺／肯定句、聽完一段佔位音樂並看到呼吸視覺，暫停後時間不走，離開或完成後沒有殘留聲音。
