# 06 UI / UX

語系 `zh-Hant`。背景 `#090908`，文字 `#f3efe6`。標題用宋體，短標用黑體。不要圓角大色塊、鼠尾草綠、蓮花或軟糊光暈。

手機寬度優先。內容欄最寬 430px，在較寬的瀏覽器裡置中。

## 路由（只在 Mobile）

| 路由 | 畫面 |
| --- | --- |
| `/` | 首頁 |
| `/session/:presetId/customize` | 調整 |
| `/session/play` | 播放。沒有記憶體中的這一輪就回首頁 |
| `/session/complete` | 完成。沒有這一輪就回首頁 |

Web 沒有這些路由。Web 只有「此體驗請用 Mobile」。

## 首頁

眉題 `Breathwork`。主句「把現在，帶到想去的地方。」

四張卡由上到下，髮絲分隔線，左邊幾何色塊：

| 預設 | 色 | 幾何 |
| --- | --- | --- |
| 開始行動 | `#d7a15f` | 實心圓 |
| 相信自己 | `#e6d3a3` | 圓環 |
| 放下焦慮 | `#7f9c98` | 橫線 |
| 睡前放下 | `#9a8aa8` | 散點 |

播放中的視覺用同一組色，但是 Pixi，不是首頁那張靜態圖。

## 調整

標題是預設名稱，副標是時長。三段：`音樂`、`視覺`、`肯定句`。

視覺選項顯示：光球、波、粒子。音樂顯示英文標題 Ambient、Organic、Deep。

肯定句每一列有「開」或「關」。點句子改字。`加一句` 新增一列並聚焦。已有 8 句就隱藏這個按鈕。

不能開始時，開始按鈕停用，並顯示「請至少留下一句」。

開始按鈕文案是「開始」。

視覺無法建立時，播放頁顯示「這一輪無法開始」與「回到首頁」。

## 播放

由上到下：離開、預設名稱、開啟或關閉音樂、開啟或關閉人聲、視覺、吸氣或吐氣、`N 秒`、肯定句、可點的進度線與圓點、`目前時間` 與 `總長`、暫停或繼續。

音樂預設關閉，按鈕文案是「開啟音樂」。點開後文案變成「關閉音樂」，並淡入。載入失敗顯示「音樂載入失敗，請再試一次」。

人聲預設關閉，按鈕文案是「開啟人聲」。點開後文案變成「關閉人聲」，吸氣說 `breath in`，吐氣說 `breath out`。畫面文字仍是「吸氣」「吐氣」。關閉人聲或暫停都會停掉正在說的英文。

肯定句置中，最多約三行。透明度由契約計算，不另做 CSS 淡化。

沒有確認對話框。

## 完成

只顯示該預設的收尾句與「回到首頁」。收尾句是畫面文案，不是 `SessionPreset` 欄位。

## 空狀態與載入

沒有獨立的空狀態插畫。缺少這一輪的資料時直接回首頁，不顯示空白播放器。

調整頁在送出開始之後、導航之前，開始按鈕停用，避免連點開出第二個音訊。
