# 02 需求與 Acceptance Criteria

資料欄位以 `05-data-models.md` 為準。畫面文案以 `06-ui-ux.md` 為準。

## AC-1 首頁

- 列出四張卡：開始行動、相信自己、放下焦慮、睡前放下。
- 每張有標題、短述、`3 分鐘`、幾何主視覺。
- 點卡片進入該預設的調整頁。

## AC-2 調整

- 可在 Ambient、Organic、Deep 中選一軌。
- 可在光球、波、粒子中選一個。
- 列出該預設 6 句肯定句。每一句可開／關、可改字。
- 可加句，連原有的最多 8 句。已滿就不再出現「加一句」。
- 空白內容不保存。清掉原有句子時，恢復原句。
- 沒有任何一句是開啟且非空白時，不能開始，並顯示「請至少留下一句」。
- 不提供呼吸調整。
- 重新整理頁面後，調整回到該預設原文。資料只在記憶體。

## AC-3 播放

- 按下開始後進入全螢幕播放。音樂淡入 1.5 秒。
- 吸氣 4 秒、吐氣 6 秒循環，直到 3 分鐘。閉氣欄位即使不為 0，也不插入閉氣相位。
- 視覺：吸氣 progress 0→1 時由小變大，吐氣 0→1 時由大變小。
- 顯示「吸氣」或「吐氣」，以及該相位剩餘秒數（無條件進位，最少顯示 1）。
- 只輪播開啟且非空白的肯定句，時間均分。每段邊緣 1.2 秒淡入淡出；若單段的 20% 更短，淡化時間用較短的那個。
- 進度條跟著這一輪已播放時間。
- 暫停同時凍結呼吸相位、秒數、肯定句、進度與音樂。繼續從同一點往下。
- 離開：立刻停音、銷毀視覺、清空這一輪、回首頁。沒有確認框。
- 自然結束：音樂淡出 1.5 秒，進入完成頁。
- 同一時間只有一個音樂 source。再次播放會先停掉上一個。
- 離開播放頁（含元件銷毀）後不得繼續出聲。
- 相位換成吸氣時說 `breath in`，換成吐氣時說 `breath out`。`hold` 只保留對應，目前沒有閉氣相位，不會被說出來。
- 英文提示走 Mobile 的 Capacitor Text-to-Speech，語言 `en-US`。新的一句會打斷上一句。暫停、離開、結束都立刻停掉語音。語音失敗不中斷這一輪。

## AC-4 完成

- 開始行動：「你已經開始了。」
- 相信自己：「你站在自己這一邊。」
- 放下焦慮：「這一口氣，先放在這裡。」
- 睡前放下：「可以休息了。」
- 「回到首頁」清空這一輪並回到首頁。

## AC-5 平台

- `apps/web` 原始碼不引用 `@ionic/`、`@capacitor/`、`pixi.js`、`tone`。
- Mobile build 輸出到倉庫根目錄 `www/`。Web build 輸出到 `dist/apps/web/browser`。
- 不建立 REST `/api`，不初始化 Firebase。
